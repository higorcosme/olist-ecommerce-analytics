# 🛒 Olist E-Commerce Analytics

Solução completa de Business Intelligence e Data Analytics construída a partir da base de dados pública do e-commerce brasileiro **Olist** (disponível no Kaggle).

---

## 📌 Sobre a Olist
A Olist conecta pequenas empresas de todo o Brasil a grandes marketplaces de forma descomplicada, formando um ecossistema líder em soluções para vendas online que integra lojas, parceiros logísticos e gestão de e-commerce.

---

## 🛠️ Tecnologias

Para transformar os dados brutos em inteligência executiva, o fluxo de dados foi estruturado da seguinte forma:

1. **Python (`Pandas`, `SQLAlchemy`):** Ingestão, limpeza, tratamento, padronização dos datasets brutos do Kaggle e conexão com banco de dados.
2. **SQL Server:** Carga dos dados, modelagem dimensional (Star Schema) e criação de queries SQL para responder perguntas de negócio.
3. **Power BI & DAX:** Construção das métricas calculadas e desenvolvimento das visões executivas focadas em *Data Storytelling*.
